# 💼 我的第一個 AI 秘書專案 (AI Executive Secretary)

大家好！這是我最近在練習 LLM 實戰與 AI Agent 架構時，用 Python 寫的一個小專案。主要是想用 `smolagents` 搭配 `Gradio` 網頁介面，做一個可以聽懂指令並自動操作工具的虛擬小秘書。

雖然目前還很陽春，但這是我學習 Agent 應用的一個小小里程碑！

## ✨ 它目前會做什麼？

這支程式裡面我寫了幾個簡單的工具給 AI 呼叫：
*   **幫忙記待辦事項**：可以把你要做的事情拆解，然後存到本機的 SQLite 資料庫裡（程式會自動產生一個 `secretary.db` 檔案來記東西）。
*   **讀取 PDF 和 Word 檔**：只要從網頁介面上傳 `.pdf` 或 `.docx`，小秘書就可以抓裡面的文字來看，幫你整理重點。
*   **假裝寄 Email**：**⚠️ 注意！這只是模擬功能！** 因為我還沒學到怎麼串接真實的郵件 API，所以小秘書只會回報「已寄出信件」，但實際上**不會真的把信寄出去**喔！😅

## 💡 可以怎麼跟它互動？

如果有機會把它跑起來，你可以試著在聊天框對它說：
*   「幫我規劃下禮拜的台北三天兩夜行程，然後加到待辦清單裡。」
*   （先上傳檔案）「幫我看一下這份企劃書的重點，然後寫一封信給老闆報告。」

目前大概是這樣，這只是我的練習記錄，程式碼如果有寫得比較菜的地方還請多多包涵！
